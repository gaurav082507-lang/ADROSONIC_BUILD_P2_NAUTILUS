# Lucen image assets

The demo currently uses lightweight local SVG placeholders so the repository never hotlinks external media. Replace these with licensed demo samples when available:

- `hero-car-damage.svg` — damaged vehicle claim hero visual
- `hero-heatmap.svg` — forensic heatmap placeholder
- `genuine-car.svg` — genuine claim sample

If raster assets are added, record source/licence here. The frontend spec requires local, licence-clear images and explicitly prohibits generic stock-photo clichés.
